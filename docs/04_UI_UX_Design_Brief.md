# UI/UX Design Brief — Visual & Interaction Design Guide

## Aesthetic
- High-end, developer-focused, dark-mode first.
- FinOps / Enterprise security vibe but with modern "Vercel/Linear" aesthetics.
- Glow effects and subtle animations for a premium feel.

## Color Palette
- **Background Base**: `#06080d`
- **Surface/Card**: `#0d1117`
- **Text Primary**: `#e6edf3`
- **Text Secondary**: `#8b949e`
- **Accent Cyan (Brand)**: `#00d2ff`
- **Accent Purple (Brand)**: `#a855f7`
- **Success/Savings**: `#00e676`
- **Danger/Waste**: `#ff4d6a`

## Typography
- **Primary Font**: `Inter` for UI clarity and readability.
- **Monospace Font**: `JetBrains Mono` or default monospace for Resource IDs and code snippets.
- **Headings**: Heavy weights (700-800) with tight tracking.

## Component Style
- **Corners**: Rounded (`8px` to `16px`).
- **Shadows**: Soft cyan/purple glows (`rgba(0, 210, 255, 0.15)`) instead of drop shadows.
- **Borders**: Subtle translucent borders (`rgba(48, 54, 61, 0.7)`).
- **Cards**: Hover effects that elevate the card and increase glow intensity.

## Key UI Patterns
- **Left Sidebar**: Fixed, icon + text nav.
- **Metric Cards**: Top grid displaying key KPIs (Waste, Savings).
- **Data Table**: Clean, bordered, with colored status badges for resource types.
- **Command Palette**: `Ctrl+K` accessible overlay with blur backdrop.

## Animations
- **Modals**: Fade and slide in.
- **Numbers**: Animated counting for financial metrics.
- **Status Dot**: Pulsing green dot to indicate system online.
